# Genre: project recap

A visual recap for context switching — what a returning developer needs to rebuild the mental model. Review family: `../references/reviews.md` applies. Target: `../targets/page/`.

## Gather

Read project identity files (`README`, changelog, package/build files), the top-level tree, current git status, recent commits, unmerged/stale branches, TODO/FIXME in recent files, progress/todo memory if present, and key entry points/source files.

## Verify

`../references/evidence.md` binds. Cite command output or `file:line` for project state, module/function/type names, recent activity, current blockers, and next-step claims. Do not fabricate momentum or rationale.

## Section skeleton

1. **Project identity** — what this repo is, stack, entry points.
2. **Architecture snapshot** — diagram of the current conceptual modules.
3. **Recent activity** — grouped narrative, not raw log.
4. **Current state** — uncommitted work, branches, TODOs, known blockers.
5. **Mental model map** — key modules, data flow, command/test/deploy paths.
6. **Risks and cognitive debt** — hotspots and gotchas.
7. **Useful commands and files** — compact reference tables.
8. **Likely next steps** — based only on evidence.
